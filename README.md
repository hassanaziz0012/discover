# Discover

Discover is a tool built to find YouTube videos that outperform their channels, preview thumbnails on different layouts, and generate quick summaries and sentiment reports.

## Features

* **Find outlier videos**: The tool tracks down videos getting significantly more views than a channel's usual average, sorting them with a custom outlier score.
* **Feeds & search**: A simple dashboard lets you search, sort, and filter videos. You can organize by outlier score, views, or date, and filter by timeframe or exclude Shorts.
* **Creator lists**: You can group channels into custom lists, update channel stats in the background, and pull in your existing YouTube subscriptions.
* **Thumbnail previewer**: This lets you test how a thumbnail looks across different screen sizes, layouts (like the sidebar, mobile, or home feed), and light or dark themes before uploading.
* **Video summaries**: Get quick breakdowns, main points, and timestamps generated by Gemma or Gemini Flash.
* **Comment sentiment**: Analyze comments to see how the audience is reacting, grouping feedback into categories like positive, negative, neutral, or mixed.

## Tech stack

* **Frontend**: Next.js, React, Tailwind CSS
* **Backend**: FastAPI, Uvicorn, UV package manager
* **APIs & models**: YouTube Data API v3, Google Gemini, Gemma

## Development

Run both the frontend and backend servers with one command:

```bash
chmod +x dev.sh
./dev.sh
```
